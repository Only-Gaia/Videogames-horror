# La Famiglia Ravenscroft

Horror in prima persona, giocabile interamente nel browser (Three.js, un unico file `index.html`, nessuna build necessaria).

## Trama

1897. La famiglia Ravenscroft scompare senza lasciare traccia. Nessuno mette più piede in quella casa.
12 gennaio 1915: il detective Elliot Crane arriva per scoprire la verità... senza sapere che questa volta è lui a cacciarsi nei guai.

## Come si gioca

- **WASD** — movimento
- **Mouse** — guarda intorno (click sul gioco per attivare il puntatore)
- **F** — accendi/spegni la torcia
- Esplora la casa su due piani, più scantinato e soffitta
- Trova **10 appunti**: 5 raccontano la storia, 5 nascondono indizi per trovare le **5 chiavi**
- Con tutte le chiavi, la porta sigillata in soffitta si apre... e dietro c'è la verità

## Come giocarci

Basta aprire `index.html` in un browser, oppure pubblicare il repository con **GitHub Pages**:

1. Carica questo repository su GitHub
2. Vai su *Settings → Pages*
3. Seleziona il branch `main` e la cartella `/ (root)`
4. Il gioco sarà online all'indirizzo `https://<tuo-utente>.github.io/<nome-repo>/`
